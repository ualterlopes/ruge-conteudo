# ruge-conteudo
Imagens e calendário das publicações da RUGE (@ruge.marketing). Pasta pública porque o Instagram precisa buscar as imagens por endereço público.

## Vídeos e projeto editável (RUGE + Nexo)
- `videos/teaser-30s/`: teaser vertical de 30 s (MP4 + trilha e efeitos separados)
- `videos/story-15s/`: story vertical de 16,5 s (MP4 + trilha e efeitos separados)
- `projeto/`: código-fonte editável de cada vídeo (Python: textos, tempos, cores, fontes e som)

Link direto de um vídeo (para o Instagram): `https://raw.githubusercontent.com/ualterlopes/ruge-conteudo/main/videos/story-15s/RUGE_Nexo_story_16s_v3.mp4`
